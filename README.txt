QUANTA MATEMÁTICA — PACOTE PARA GITHUB PAGES

1. Extraia todo o conteúdo deste pacote na raiz de um repositório do GitHub.
2. Envie os arquivos index.html, .nojekyll, README.txt e a pasta assets.
3. No GitHub, abra Settings > Pages.
4. Em Build and deployment, selecione Deploy from a branch.
5. Escolha a branch main, pasta /(root), e clique em Save.

O site é estático: não exige npm, servidor ou etapa de compilação no GitHub.
O progresso das aulas, o Pomodoro e o tempo total ficam salvos no navegador do estudante.
Os slides e vídeos incorporados precisam de conexão com a internet.

CONTEÚDO DESTA VERSÃO
- 9º ano: 1º trimestre (nivelamento N1–N10 e aulas 1–40) e 2º trimestre.
- 1ª e 2ª séries: 2º trimestre.
